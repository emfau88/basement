# Bulk 23 — Desktop integration

The Desktop studio now uses one continuous dark PBR cement floor at a consistent scale. Rugs remain intentional overlays for Games, Web and Archive rather than disconnected floor materials.

The timber ceiling slats were removed in favor of a quiet recessed acoustic raft. The obsolete entrance guide rails, signal-button plate and colored floor markers were also removed, clearing the Studio overview and strengthening the five-zone composition.
